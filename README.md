# 👔 Employee Payroll System

A **Java-based Employee Payroll Management System** that provides REST APIs for managing employee records and payroll calculations.

This project demonstrates core backend functionalities such as CRUD operations, payroll computation, and data persistence.

---

## 🚀 Features

- Add, update, delete, and list employees
- Calculate payroll details
- REST-based endpoints
- In-memory or persistent database support
- Clear separation of concerns
- Exception handling and validation

---

## 🛠 Technologies Used

| Technology | Role |
|------------|------|
| Java | Core language |
| Spring Boot | Application framework |
| Spring Data JPA | ORM for data access |
| Hibernate | JPA implementation |
| H2 / MySQL | Database |
| Maven | Build & dependency management |
| Lombok | Boilerplate reduction |
| Validation | Input validation |
